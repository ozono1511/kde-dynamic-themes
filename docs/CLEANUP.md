# V3 cleanup — preserve live user state

V3's **distribution is already clean**: no historical gallery versions, caches, backups, personal images, Matugen executable or temporary tests are packed. Only the source package, installer, icon, tests, and documentation are included.

The old `~/Projects/kde-dynamic-themes` is both (a) the V2.5/V2.6 fallback and (b) the **current data location used by V3**. It must NOT be deleted or renamed. This directory includes the Matugen binary, wallpapers, configuration, color palettes and recovery backups. The previous code in `app/` is intentionally retained until the V3 launcher is tested after a reboot.

The `cleanup-review.json` generated by the V2.6.2 script was produced on the user's computer but its **contents were not provided for verification**. Generating a file does not authorize any file deletion. No assumptions about its listed paths can be made.

Recommended deferred, selective housekeeping AFTER V3 validation:

- Check what is referenced by local launcher files, shell shortcuts, and active Python modules before deleting historical `app/gallery_v*.py`, legacy theme engines or snapshots.
- `app/__pycache__` and historical distribution extraction caches are regenerable; delete only after you have verified their contents are not active inputs. The amount saved is small.
- Never delete `config/`, `backups/`, `wallpapers/`, `bin/`, `presets/`, active `.colors` or Konsole `.colorscheme` files during this migration.
- Do not remove generated `KDT*.colors` or `KDT*.colorscheme` files without checking active KDE color schemes and all Konsole profiles; historical windows and sessions may refer to them.
- Keep at least one verified fallback for application code. A V3 installer only owns its new XDG directories/launcher; it does not take ownership of legacy data.

Run read-only audit when desired:

```bash
python3 scripts/review_cleanup.py --output ./cleanup-review.json
```

The audit is informational, not proof that it is safe to delete every candidate. **There is no one-click recursive legacy deletion in the stable release.**
